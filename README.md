> Contains information about PER-3.1 Code Style for PHP. 

## Install

### Via NPX

```shell
npx skills add TheDragonSkills/php-code-style
```

### Via `llm/skills`

You can also install and update skills using the [**llm/skills**](https://github.com/roxblnfk/skills) library:

```bash
composer skills:add TheDragonSkills/php-code-style
```

## Usage

Ask about code style or simply call the skill:

```bash
$php-code-style <PHP files or diff> [review|apply]
```
